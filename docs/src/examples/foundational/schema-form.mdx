The same sign-up form, validated by five schema libraries. In each, the inputs hold strings and `onSubmit` receives the parsed output: the name trimmed, the age a number. See [Schema validation](../../guide/core/schema-validation.mdx).

- **Zod, Valibot, ArkType, Yup (1.7+)** implement [Standard Schema](https://standardschema.dev): pass the schema to the `schema` prop. No resolver package; `onSubmit` is typed by the schema output.
- **Ajv** (JSON Schema): pass a resolver from `@hookform/resolvers` to `formOptions.resolver`.

Field `rules` are not used with a schema: all validation, messages included, lives in the schema. The `*` marker comes from `rules.required`, so set `required: true` on a field to show it.
