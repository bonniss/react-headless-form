## Shared setup, `t` per form

What does not change with the language goes into `setupForm` once: the validation keys. Each `<Form>` passes only `t`; the two are merged key by key (_v0.22+_).

```tsx file="../_shared/i18n/form.tsx"
```

Override one key (`i18nConfig={{ t }}`) or all of them on a given form; a key set to `undefined` drops the setup's value for that form.

When `t` needs a few lines of wiring (your own store, an adapter around the library's function), put them in a hook of your app, `useI18nConfig()`, and pass its result to every form: `<Form i18nConfig={useI18nConfig()} />`. When the library's `t` fits as is, pass it directly.

## Your own translator

A language store of a few lines: `getLang` / `setLang` decide where the language lives (localStorage here, a cookie or the URL works the same), `useSyncExternalStore` re-renders the form when it changes, and `t` is a lookup in the JSON.

| Pros | Cons (what a library gives you) |
|---|---|
| No dependency, a few dozen lines you can read | Plurals and ICU syntax (`{count, plural, …}`) |
| Store the language anywhere: localStorage, a cookie, the URL | Number, date and currency formatting per locale |
| **Translate outside React**: `translate(getLang(), key)` in services, API error mapping, a module-level Zod error map, toasts | Loading a locale only when it is used |
| Easy to debug | Key extraction, translation tooling, type-checked keys, fallback locales |

Good for a small or medium app with a few languages and simple messages. Once you need plurals, formatting or a translation workflow, use a library. Libraries translate outside React too, each in its own way: `i18next.t`, Lingui's `i18n._`, Paraglide's `m.key()` with `getLocale()`, react-intl's `createIntl()`.

## With an i18n library

The same form with each library: `t` comes from the library's hook, so the form follows the language, and the rest of the config comes from the shared setup. Submit it empty, then switch the language: the label, the placeholder and the error follow, and the value is kept.
