# Arco Design

The [registration form demo](./index.mdx#live-demos) written with Arco Design, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and layout) and the config. `props` use Arco Design's own API, typed by its components.
- `fields.tsx`: the adapters, typed with Arco Design's own props through `AdapterProps`.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Input`, `Select` and `Checkbox` pass the **value** to `onChange`, not an event.
- Arco's `Form.Item` needs Arco's own `Form`, so label and message are plain markup.
- Import `@arco-design/web-react/dist/css/arco.css`; `ConfigProvider locale` sets the built-in texts (here it follows the language switch).
