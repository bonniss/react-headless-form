# ArkType

[ArkType](https://arktype.io) implements [Standard Schema](https://standardschema.dev), so the schema goes straight into the `schema` prop: no `@hookform/resolvers`, and `onSubmit` receives the schema **output** (here the age is parsed to a number). See [Schema validation](../../../guide/core/schema-validation.mdx).

```sh
pnpm add arktype
```

Put a custom `message` on the type that performs the check: after a parse (`string.integer.parse`), configure the target type (`type("number >= 18").configure(...)`).

The form itself is shared by the Zod, Valibot and ArkType pages ([`EgSchemaLibForm`](#form)); only the schema differs.
