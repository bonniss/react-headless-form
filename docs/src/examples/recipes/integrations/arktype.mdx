This recipe demonstrates how to use [Arktype](https://arktype.io/) with BlueForm.

```sh
pnpm add arktype @hookform/resolvers
```

Pass the resolver through `formOptions`. Field-level `rules` are disabled while a resolver is set, so keep all validation in the schema — see [Schema validation](../../../guide/core/schema-validation.mdx).

```tsx
import { type } from "arktype"
import { arktypeResolver } from "@hookform/resolvers/arktype"

const schema = type({
  name: "string > 0",
  email: "string.email",
})
type FormData = typeof schema.infer

<Form<FormData>
  formOptions={{ resolver: arktypeResolver(schema) }}
  config={{
    name: { type: "text", label: "Name" },
    email: { type: "text", label: "Email" },
  }}
  onSubmit={(data) => save(data)}
/>
```
