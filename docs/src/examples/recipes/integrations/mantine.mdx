# Mantine

The [registration form demo](./index.mdx#live-demos) written with Mantine, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and grid) and the config. `props` use Mantine's own API, typed by its components.
- `fields.tsx`: the adapters, typed with Mantine's own props minus what `useField()` controls.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Select` passes the **value** to `onChange` (not an event); `TextInput` / `Checkbox` pass events.
- Wrap the app in `MantineProvider` and import `@mantine/core/styles.css`.

:::tip
`main.tsx` only mounts the docs' demo stage (language switch, payload drawer); your app renders `Form` itself. See [Connect your UI kit](./index.mdx#bring-your-own-library).
:::
