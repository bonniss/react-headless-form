# Mantine

The [shared sample form](./index.mdx#sample-form) (rules, a JSON condition, a computed slug, a nested section and an array) rendered with Mantine. Only the field adapters below are library-specific.

- `Select` passes the **value** to `onChange` (not an event); `TextInput` / `Checkbox` pass events.
- Wrap the app in `MantineProvider` and import `@mantine/core/styles.css`.
