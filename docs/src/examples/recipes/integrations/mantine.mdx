# Mantine

The [shared demo form](./index.mdx#what-each-field-shows) (rules, JSON conditions, computed values, nested sections, an invoice array with per-row errors, i18n) rendered with Mantine. Only the adapters below are library-specific; the logic is in [`shared/config.tsx`](./index.mdx#one-logic-ui-only-differences).

- `Select` passes the **value** to `onChange` (not an event); `TextInput` / `Checkbox` pass events.
- Wrap the app in `MantineProvider` and import `@mantine/core/styles.css`.
