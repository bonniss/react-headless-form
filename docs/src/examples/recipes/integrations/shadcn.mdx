# shadcn/ui

The [registration form demo](./index.mdx#live-demos) written with shadcn/ui, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and grid) and the config. `props` use shadcn/ui's own API, typed by its components.
- `fields.tsx`: the adapters, typed with shadcn/ui's own props minus what `useField()` controls.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- shadcn components are plain elements you own, so adapters are a few lines. The demo keeps its primitives minimal (`ui.tsx`, no Radix); with the real `Select` / `Checkbox` from `npx shadcn add`, use `onValueChange` / `onCheckedChange` (value, not event).
- Tailwind v4 scans only this demo, so its preflight does not leak into the other demos.
