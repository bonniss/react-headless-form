# Material UI

The [shared sample form](./index.mdx#sample-form) (rules, a JSON condition, a computed slug, a nested section and an array) rendered with Material UI. Only the field adapters below are library-specific.

- One small hook (`useTextFieldProps`) maps `useField()` to `TextField` props; text, long text and select reuse it (`select` + `MenuItem`).
- Pass the field `ref` as `inputRef` so `setFocus` / focus on error work.
