# animal-island-ui

The [shared sample form](./index.mdx#sample-form) (rules, a JSON condition, a computed slug, a nested section and an array) rendered with animal-island-ui. Only the field adapters below are library-specific.

- `Select` options use `key` (not `value`) and `onChange` receives the key.
- There is no `TextArea`; long text uses `Input`. Its `Checkbox` is a group (array of values), so a boolean field uses `Switch`.
- Import `animal-island-ui/style` once.
