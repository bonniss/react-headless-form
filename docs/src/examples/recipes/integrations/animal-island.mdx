# animal-island-ui

The [shared demo form](./index.mdx#what-each-field-shows) (rules, JSON conditions, computed values, nested sections, an invoice array with per-row errors, i18n) rendered with animal-island-ui. The logic comes from [`shared/logic.ts`](./index.mdx#one-logic-ui-only-differences). This library adds two files:

- `fields.tsx`: adapters typed with animal-island-ui's own props (`InputProps` minus what `useField()` controls).
- `config.tsx`: the config. Each field spreads its logic (`...logic.email`) and sets `props` with animal-island-ui's API, typed and autocompleted as animal-island-ui's props.

- `Select` options use `key` (not `value`) and `onChange` receives the key.
- There is no `TextArea`; long text uses `Input`. Its `Checkbox` is a group (array of values), so a boolean field uses `Switch`.
- Import `animal-island-ui/style` once.
