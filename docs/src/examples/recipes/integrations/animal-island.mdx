# animal-island-ui

The [registration form demo](./index.mdx#live-demos) written with animal-island-ui, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and grid) and the config. `props` use animal-island-ui's own API, typed by its components.
- `fields.tsx`: the adapters, typed with animal-island-ui's own props minus what `useField()` controls.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Select` options use `key` (not `value`) and `onChange` receives the key.
- There is no `TextArea`; long text uses `Input`. Its `Checkbox` is a group (array of values), so a boolean field uses `Switch`.
- Import `animal-island-ui/style` once.
