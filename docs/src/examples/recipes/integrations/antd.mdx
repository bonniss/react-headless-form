# Ant Design

The [registration form demo](./index.mdx#live-demos) written with Ant Design, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and grid) and the config. `props` use Ant Design's own API, typed by its components.
- `fields.tsx`: the adapters, typed with Ant Design's own props minus what `useField()` controls.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Form.Item` is used for **layout only** (label, help, status); values and errors come from `useField()`, so no antd `Form` instance is involved.
- `Select` passes the value to `onChange`; `Input` / `Checkbox` pass events.

:::tip
`main.tsx` only mounts the docs' demo stage (language switch, payload drawer); your app renders `Form` itself. See [Connect your UI kit](./index.mdx#bring-your-own-library).
:::
