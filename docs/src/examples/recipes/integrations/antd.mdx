# Ant Design

The [shared sample form](./index.mdx#sample-form) (rules, a JSON condition, a computed slug, a nested section and an array) rendered with Ant Design. Only the field adapters below are library-specific.

- `Form.Item` is used for **layout only** (label, help, status); values and errors come from `useField()`, so no antd `Form` instance is involved.
- `Select` passes the value to `onChange`; `Input` / `Checkbox` pass events.
