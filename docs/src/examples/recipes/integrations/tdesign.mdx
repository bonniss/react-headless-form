# TDesign

The [registration form demo](./index.mdx#live-demos) written with TDesign, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and layout) and the config. `props` use TDesign's own API, typed by its components.
- `fields.tsx`: the adapters, typed with TDesign's own props through `AdapterProps`.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Input`, `Select` and `Checkbox` pass the **value** to `onChange`; `Input` has no `type="email"` (a type error in the config).
- A wrapping `<label>` names the input, since TDesign `Input` takes no `id`.
- Import `tdesign-react/es/style/index.css`; `ConfigProvider globalConfig` sets the built-in texts, which default to Chinese.

:::tip
`main.tsx` only mounts the docs' demo stage (language switch, payload drawer); your app renders `Form` itself. See [Connect your UI kit](./index.mdx#bring-your-own-library).
:::
