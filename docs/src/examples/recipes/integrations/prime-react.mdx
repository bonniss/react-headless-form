# PrimeReact

The [registration form demo](./index.mdx#live-demos) written with PrimeReact, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and layout) and the config. `props` use PrimeReact's own API, typed by its components.
- `fields.tsx`: the adapters, typed with PrimeReact's own props through `AdapterProps`.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Dropdown` and `Checkbox` pass `e.value` / `e.checked`, not the DOM event.
- Import a theme (`primereact/resources/themes/lara-light-blue/theme.css`) and wrap the app in `PrimeReactProvider`.
- PrimeReact v11 is a different, unstyled primitives library; this demo uses v10.
