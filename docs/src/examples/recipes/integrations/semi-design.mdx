# Semi Design

The [registration form demo](./index.mdx#live-demos) written with Semi Design, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and layout) and the config. `props` use Semi Design's own API, typed by its components.
- `fields.tsx`: the adapters, typed with Semi Design's own props through `AdapterProps`.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Input` passes the value first (and the event second); `Select` takes `optionList`.
- With React 19 use `@douyinfe/semi-ui-19`; import its `dist/css/semi.min.css`.
- `LocaleProvider` sets the built-in texts (here it follows the language switch).

:::tip
`main.tsx` only mounts the docs' demo stage (language switch, payload drawer); your app renders `Form` itself. See [Connect your UI kit](./index.mdx#bring-your-own-library).
:::
