# Chakra UI

The [registration form demo](./index.mdx#live-demos) written with Chakra UI, self-contained:

- `form.tsx`: `setupForm` (with a `renderRoot` for the title and layout) and the config. `props` use Chakra UI's own API, typed by its components.
- `fields.tsx`: the adapters, typed with Chakra UI's own props through `AdapterProps`.
- `main.tsx`: mounts it in the demo stage (header, payload drawer).

- `Field.Root` carries the label, error and required / disabled / read-only state; the select is `NativeSelect` (its options are `<option>` children).
- `Checkbox.Root` reports `{ checked }` in `onCheckedChange`.
- Wrap the app in `ChakraProvider value={defaultSystem}`.

:::tip
`main.tsx` only mounts the docs' demo stage (language switch, payload drawer); your app renders `Form` itself. See [Connect your UI kit](./index.mdx#bring-your-own-library).
:::
