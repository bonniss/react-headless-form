# Valibot

[Valibot](https://valibot.dev) implements [Standard Schema](https://standardschema.dev), so the schema goes straight into the `schema` prop: no `@hookform/resolvers`, and `onSubmit` receives the schema **output** (here the age is parsed to a number). See [Schema validation](../../../guide/core/schema-validation.mdx).

```sh
pnpm add valibot
```

`v.toNumber()` inside the pipe converts the input string; the output type follows.

The form itself is shared by the Zod, Valibot and ArkType pages ([`EgSchemaLibForm`](#form)); only the schema differs.
