# Zod

[Zod](https://zod.dev) implements [Standard Schema](https://standardschema.dev), so the schema goes straight into the `schema` prop: no `@hookform/resolvers`, and `onSubmit` receives the schema **output** (here the age is parsed to a number). See [Schema validation](../../../guide/core/schema-validation.mdx).

```sh
pnpm add zod
```

`z.coerce.number<string>()` keeps the input type a string (what the text input holds) while the output is a number.

The form itself is shared by the Zod, Valibot and ArkType pages ([`EgSchemaLibForm`](#form)); only the schema differs.
