This recipe demonstrates how to use [Zod](https://zod.dev/) with BlueForm.

```sh
pnpm add zod @hookform/resolvers
```

Pass the resolver through `formOptions`. Field-level `rules` are disabled while a resolver is set, so keep all validation in the schema — see [Schema validation](../../../guide/core/schema-validation.mdx).

```tsx
import { z } from "zod"
import { zodResolver } from "@hookform/resolvers/zod"

const schema = z.object({
  name: z.string().min(1, "Name is required"),
  email: z.string().email("Invalid email"),
})
type FormData = z.infer<typeof schema>

<Form<FormData>
  formOptions={{ resolver: zodResolver(schema) }}
  config={{
    name: { type: "text", label: "Name" },
    email: { type: "text", label: "Email" },
  }}
  onSubmit={(data) => save(data)}
/>
```
